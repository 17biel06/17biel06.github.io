Codificador URL y Base64

Codifica y decodifica texto para URL o Base64 UTF-8. El resultado se procesa en este navegador; recuerda que Base64 no cifra ni protege información.

Cómo funciona

La codificación URL transforma caracteres para que puedan viajar en un componente de una dirección web. Base64 representa bytes con caracteres imprimibles y suele aparecer en datos, cabeceras y formatos de intercambio. Ninguna de las dos técnicas es un mecanismo de cifrado.

Ejemplo

El texto hola mundo se codifica como componente URL hola%20mundo y en Base64 UTF-8 como aG9sYSBtdW5kbw==.

Preguntas frecuentes

¿Base64 oculta una contraseña? No, cualquiera puede decodificarlo. No lo uses como protección.
¿Se admiten tildes y emoji? Sí, Base64 convierte primero el texto a UTF-8.

Privacidad: las entradas se procesan en tu navegador. No pegues secretos en un dispositivo compartido.
