- Propósito: herramientas gratuitas de redes y ciberseguridad en español.
- Hospedaje previsto: GitHub Pages, dentro de `17biel06/17biel06.github.io`, ruta `/redeslab/`.

## Investigación inicial (20-10-2026)
No se dispone de acceso a Google Keyword Planner, Search Console ni una herramienta de volumen. No se atribuyen volúmenes mensuales ni dificultad numérica. Google Trends solo publica interés relativo normalizado (0–100), que no equivale al volumen absoluto.

### Oportunidad elegida
Herramientas de redes y seguridad cliente para público hispanohablante. Es una hipótesis de producto, no una afirmación de liderazgo o bajo volumen. La SERP ya contiene calculadoras IPv4/IPv6, CIDR y VLSM (por ejemplo AP Interactive, ToolsSoup, Toolv y Calcadabra), señal de una intención existente y competencia real. La diferenciación inicial será privacidad local, explicaciones en español y herramientas para subnetting/VLSM/IPv6. La ventaja no está demostrada; se revisará con impresiones y clics de Search Console tras indexación.

## Páginas publicadas en el lanzamiento
Calculadora de subredes IPv4; división CIDR; planificador VLSM; calculadora de prefijo IPv6; conversor IP decimal/binario; wildcard Cisco; generador de contraseñas; SHA-256; codificador URL/Base64; generador UUID v4; privacidad.
