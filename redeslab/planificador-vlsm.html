Planificador VLSM IPv4

Escribe la red disponible y una necesidad de hosts por línea. El planificador ordena los bloques de mayor a menor y propone subredes alineadas sin solapamientos.

Cómo funciona

VLSM (Variable Length Subnet Mask) permite usar prefijos diferentes dentro de un mismo bloque. Para cada necesidad, se reserva el menor bloque que pueda alojar los hosts solicitados, redondeando la capacidad a una potencia de dos. Conviene asignar primero los bloques mayores: así se reduce la fragmentación y es menos probable dejar huecos inutilizables.

Ejemplo

Si una VLAN necesita 50 hosts, un /26 contiene 64 direcciones (62 utilizables en una LAN IPv4 normal), mientras que un /27 solo permite 30 hosts. El planificador reserva el bloque adecuado y continúa con la siguiente necesidad.

Preguntas frecuentes

¿Qué significa VLSM? Máscara de subred de longitud variable: varias subredes con tamaños diferentes dentro de un rango mayor.
¿El resultado es un diseño definitivo? Es una propuesta de direccionamiento; comprueba reservas, gateways y políticas de tu red antes de aplicarla.
