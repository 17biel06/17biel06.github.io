Generador de UUID v4

Genera identificadores UUID versión 4 mediante aleatoriedad criptográfica del navegador. Úsalos como identificadores técnicos, no como secretos o contraseñas.

Cómo funciona

Un UUID v4 tiene 128 bits con campos reservados para indicar la versión y la variante; los demás bits se generan aleatoriamente. Es adecuado para crear identificadores con baja probabilidad de colisión en muchas aplicaciones, aunque no sustituye una clave de base de datos diseñada para cada caso.

Ejemplo

Un UUID v4 tiene una forma como xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx. La herramienta limita cada petición a 50 identificadores y usa el generador seguro del navegador.

Preguntas frecuentes

¿Un UUID es una contraseña segura? No es una recomendación para credenciales; usa un gestor y un generador de contraseñas.
¿Se repite? La probabilidad de colisión es muy baja, pero no es matemáticamente imposible.

Privacidad: las entradas se procesan en tu navegador. No pegues secretos en un dispositivo compartido.
