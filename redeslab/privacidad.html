Privacidad

Las herramientas calculan en el navegador. Esta versión no incluye analítica, publicidad, cuentas ni formularios de contacto.

Datos introducidos

Las direcciones IP, textos, contraseñas y demás valores se procesan en tu dispositivo mediante JavaScript. No se envían a una API de RedesLab ni se guardan en una base de datos. No pegues información sensible si compartes el dispositivo o el navegador.

Conexión y alojamiento

La web está alojada en GitHub Pages. Como cualquier alojamiento web, GitHub puede procesar datos técnicos de las solicitudes para prestar y proteger el servicio. Consulta la política de privacidad de GitHub para conocer sus prácticas.

Analítica y publicidad

En esta versión no se ha instalado analítica ni publicidad. La web no vende datos personales.

Contacto

Esta versión no publica una dirección de contacto. Se añadirá si hace falta gestionar consultas de forma sostenible.
