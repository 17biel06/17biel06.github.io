Generador de hash SHA-256

Escribe texto y calcula su huella SHA-256 sin subirlo. Este hash sirve para comparar datos; por sí solo no cifra el contenido ni demuestra quién lo creó.

Cómo funciona

SHA-256 es una función hash criptográfica de la familia SHA-2. Produce una salida de 256 bits (64 caracteres hexadecimales) para cualquier longitud de entrada. Cambios pequeños en el texto suelen producir un hash completamente distinto. Un hash no se puede descifrar como si fuera un cifrado.

Ejemplo

Para verificar un archivo, hay que calcular el hash del archivo exacto y compararlo con una referencia confiable del mismo artefacto. En esta versión se calcula el hash de texto UTF-8.

Preguntas frecuentes

¿SHA-256 cifra el texto? No, produce un resumen unidireccional.
¿Se guarda lo que pego? No se transmite ni se guarda: Web Crypto calcula el hash localmente.
