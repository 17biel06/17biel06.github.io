Calculadora de prefijo IPv6

Introduce una IPv6 y su longitud de prefijo para conocer los límites del bloque y el número de direcciones incluidas. No se consulta ningún servicio externo.

Cómo funciona

IPv6 usa direcciones de 128 bits. El prefijo identifica la parte de red; los bits restantes forman el espacio de direcciones del bloque. La abreviatura :: sustituye uno o más grupos consecutivos de ceros, pero solo puede aparecer una vez en una dirección.

Ejemplo

Un prefijo /64 deja 64 bits para identificadores dentro del bloque, es decir, 2^64 direcciones. En esta página el rango se muestra en formato completo de ocho grupos hexadecimales.

Preguntas frecuentes

¿Se admiten IPv4 incrustadas dentro de IPv6? Esta versión acepta notación hexadecimal con grupos comprimidos y rechaza el sufijo IPv4 decimal.
¿Qué significa /64? Los primeros 64 bits forman el prefijo de red.
