Dividir una red CIDR en subredes iguales

Indica una red IPv4 y el prefijo de cada subred resultante. La herramienta muestra hasta 64 bloques para que puedas revisar la distribución sin salir del navegador.

Cómo funciona

Para dividir una red en bloques iguales, aumenta el prefijo CIDR. La diferencia entre el prefijo nuevo y el original determina cuántas subredes caben: 2^(prefijo nuevo − prefijo original). El prefijo nuevo debe ser igual o mayor que el original y no puede superar /32.

Ejemplo

Una red 10.0.0.0/24 dividida en /26 produce cuatro bloques de 64 direcciones: 10.0.0.0/26, 10.0.0.64/26, 10.0.0.128/26 y 10.0.0.192/26.

Preguntas frecuentes

¿Por qué solo muestra 64 subredes? Para mantener el resultado manejable; el bloque completo se calcula y la lista se limita visualmente.
¿Puedo dividir en tamaños distintos? Para eso usa el planificador VLSM.

Privacidad: las entradas se procesan en tu navegador. No pegues secretos en un dispositivo compartido.
